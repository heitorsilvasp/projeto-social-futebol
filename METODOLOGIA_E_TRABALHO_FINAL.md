## 1. Objetivo do projeto
Desenvolver uma aplicação web informativa para apresentar projetos sociais de futebol, suas atividades e conteúdos orientativos sobre desenvolvimento esportivo. A proposta busca organizar informações em formato acessível e demonstrar como tecnologias web podem contribuir para a divulgação de iniciativas comunitárias.

## 2. Metodologia
O projeto foi organizado em etapas:
1. Definição do público e do problema: dificuldade de reunir, em um só local, informações introdutórias sobre projetos sociais de futebol.
2. Planejamento das informações: nome do projeto, região, faixa etária e descrição das atividades.
3. Prototipação da interface: criação de uma página responsiva com seções de apresentação, projetos, orientação sobre avaliações e contato.
4. Desenvolvimento front-end: utilização de HTML para estruturar o conteúdo, CSS para apresentação visual e JavaScript para busca, filtros, menu móvel e validação demonstrativa de formulário.
5. Testes funcionais: abertura no navegador, teste da busca, seleção das faixas etárias, navegação e preenchimento do formulário.
6. Revisão e documentação: registro das funcionalidades, limitações e possibilidades de melhoria.

### Diagrama da metodologia
Definição do problema → Planejamento do conteúdo → Prototipação da interface → Desenvolvimento HTML/CSS/JavaScript → Testes funcionais → Documentação e apresentação.

## 3. Resultados esperados
Espera-se obter uma aplicação web simples, responsiva e fácil de navegar, capaz de apresentar informações de projetos demonstrativos e permitir sua filtragem por região/nome e faixa etária. Espera-se também aplicar conceitos introdutórios de desenvolvimento front-end e produzir uma demonstração que possa ser apresentada em vídeo.
