# Raízes do Futebol

Protótipo acadêmico de aplicação web para apresentar projetos sociais de futebol e informações sobre desenvolvimento esportivo de crianças e adolescentes.

## Tecnologias
- HTML5: estrutura e conteúdo
- CSS3: layout responsivo e identidade visual
- JavaScript: busca, filtros, menu móvel e validação demonstrativa do formulário

## Como executar
1. Baixe ou extraia os arquivos.
2. Abra a pasta do projeto.
3. Clique duas vezes em `index.html` para abrir no navegador.
4. Teste a busca por nome/região, o filtro por idade e o formulário.

Não é necessário instalar Node.js, banco de dados ou dependências.

## Funcionalidades
- Página inicial e apresentação da missão
- Cartões de projetos demonstrativos
- Busca por nome, região ou descrição
- Filtro por faixa etária
- Menu responsivo para telas menores
- Validação local de formulário sem envio ou armazenamento de dados

## Observação importante
Os nomes e dados dos projetos exibidos são exemplos fictícios para demonstração da interface. Não representam organizações verificadas nem vagas reais. Para uma aplicação pública, os dados devem ser substituídos por informações confirmadas com os responsáveis, com cuidado especial à privacidade de crianças e adolescentes.

## Escopo e limitações
Esta é uma versão front-end estática. Não possui login, banco de dados, painel administrativo ou envio real de formulários.
